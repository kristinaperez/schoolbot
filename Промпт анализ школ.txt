Создай один самодостаточный файл index.html (без внешних зависимостей, кроме CDN Tailwind CSS) для деплоя на Netlify. Это landing page + интерактивная страница Telegram-бота для AI-аудита онлайн-школ.

О продукте: Telegram-бот принимает URL сайта онлайн-школы, проводит комплексный AI-аудит через Claude (с web_search) по 40 разделам (продукт, маркетинг, продажи, CRO, SEO, GEO, AI-автоматизация, vibe coding, безопасность, экономика и т.д.), генерирует красивый PDF-отчёт и отправляет его на email. В конце отчёта — контакты агентства.

Структура страницы:





Hero-секция с заголовком, подзаголовком и CTA-кнопкой «Провести аудит»



«Как это работает» — 4 шага (ссылка → анализ → email → PDF на почту)



Интерактивное демо — имитация интерфейса Telegram-чата в рамке телефона/окна:





Поле ввода URL с валидацией



После отправки URL — анимированные статусы («🔎 Изучаю сайт…», «📊 Собираю данные о конкурентах…») с задержками 6с и 16с



Через 30с появляется запрос email



После ввода email — финальное сообщение «✅ Отчёт отправлен на почту!»



Реальный бэкенд я подгружаю сейчас в память, это 



Что входит в отчёт — сетка из 12–16 карточек с ключевыми разделами аудита (иконки emoji)



Преимущества — AI + web search, 40 разделов, PDF-отчёт, коммерческие рекомендации



CTA-блок с кнопкой «Открыть бота в Telegram» (ссылка на t.me/@OnlineSchoolDiagnosisBot)



Footer с контактами

Технические требования:





Один файл, inline CSS + vanilla JS (или только Tailwind через CDN)



Адаптивный дизайн (mobile-first)



Современная цветовая схема: индиго/фиолетовый (#4f46e5) как акцент, светлый фон



Плавные анимации появления сообщений в чате (fade-in + slide-up)



Валидация URL и email на клиенте (regex)



Rate limiting имитация: не чаще 1 аудита на пользователя



Meta-теги для SEO (title, description, OG)



Favicon inline (data URI)



Готов к drag-and-drop деплою на Netlify (просто index.html в корне)

Важно: страница связанная с реальным ботом. 

Все AI-ответы и PDF — реальные. 

На странице должно быть понятно, что это реальная веб-страница Telegram-бота.
