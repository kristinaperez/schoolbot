# School Audit Bot

Telegram-бот на **Node.js + Telegraf**, который проводит комплексный AI-аудит
онлайн-школы по ссылке на сайт и присылает результат PDF-файлом на email.

## Как это работает

1. Пользователь присылает боту ссылку на сайт школы.
2. Бот в фоне отправляет большой промпт-аудит (см. `src/prompt.js`) в Anthropic API
   (модель Claude, с включённым инструментом `web_search`, чтобы изучить не только
   сайт, но и соцсети/отзывы/конкурентов).
3. Пока идёт анализ, бот показывает "прогресс" (статусные сообщения), а спустя
   `FAKE_PROGRESS_DELAY_MS` (по умолчанию 30 сек) просит email.
4. После получения email и завершения анализа бот:
   - конвертирует Markdown-отчёт в красиво оформленный PDF (`src/pdf.js`, через
     `markdown-it` + `puppeteer`);
   - отправляет PDF на email через SMTP (`src/mailer.js`, `nodemailer`);
   - пишет пользователю в Telegram, что отчёт отправлен.
5. В PDF **не включается** пункт 40.4 «Что можно продать школе» — этот пункт
   остаётся только "внутри" промпта и используется агентством отдельно, не
   попадая в отчёт, который получает школа. Это задаётся прямо в промпте
   (`src/prompt.js`), а не пост-обработкой текста — так надёжнее.
6. В конце каждого PDF — блок с контактами:
   **Кристина Перез — https://t.me/KristinaPerez9** (задаётся в `.env`).

## Rate limiting

Реализован в `src/rateLimiter.js`: если один пользователь присылает больше
`RATE_LIMIT_MAX_REQUESTS` сообщений за `RATE_LIMIT_WINDOW_MS` миллисекунд
(по умолчанию — больше 4 сообщений за 1 секунду), он получает временный бан на
`RATE_LIMIT_BAN_MS` (по умолчанию 15 секунд) — все его сообщения в это время
игнорируются, с одним уведомлением о бане.

## Установка

```bash
npm install
cp .env.example .env
# заполните .env реальными значениями (см. ниже)
npm start
```

### Обязательные переменные `.env`

| Переменная | Что это |
|---|---|
| `BOT_TOKEN` | Токен от @BotFather |
| `ANTHROPIC_API_KEY` | Ключ API Anthropic |
| `ANTHROPIC_MODEL` | Модель (по умолчанию `claude-sonnet-5`) |
| `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS`, `MAIL_FROM` | Данные SMTP для отправки писем с PDF |
| `CONTACT_NAME`, `CONTACT_TELEGRAM` | Контакты, которые печатаются в PDF |

Полный список — в `.env.example`.

## Важные технические заметки

- **Puppeteer** при `npm install` скачивает Chromium (~200–300 МБ) — нужен
  доступ в интернет на машине, где вы устанавливаете зависимости.
- Итоговый отчёт по промпту — очень большой (40 разделов с таблицами).
  `ANTHROPIC_MAX_TOKENS` в `.env` выставлен с запасом (8192), но если модель
  всё равно обрезает отчёт — увеличьте лимит или, при необходимости, разбейте
  генерацию на несколько запросов (например, по блокам разделов) — точку
  расширения см. в `src/claudeClient.js`.
- Хранилище сессий (`src/session.js`) и rate-limiter (`src/rateLimiter.js`) —
  in-memory (`Map`), рассчитаны на один процесс/инстанс бота. Для нескольких
  инстансов нужно вынести состояние в Redis.
- Валидация URL/email — упрощённая regex-проверка (`src/bot.js`). При
  необходимости замените на более строгую библиотеку (`validator.js`).

## Структура проекта

```
src/
  index.js         — точка входа, запуск polling
  bot.js            — сценарий диалога (Telegraf)
  config.js         — чтение .env
  rateLimiter.js     — anti-flood middleware
  session.js         — состояние диалога на пользователя
  prompt.js          — мастер-промпт аудита (40 разделов)
  claudeClient.js    — вызов Anthropic API (+ web_search)
  pdf.js             — Markdown → HTML → PDF (puppeteer)
  mailer.js          — отправка PDF на email (nodemailer)
```
